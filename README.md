# Лендинг игры

[![hexlet-check](https://github.com/kicha3007-boop/tailwind-project-446/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/kicha3007-boop/tailwind-project-446/actions)

Сверстайте на Tailwind лендинг игры про мир из блоков. Меню, вкладки режимов, галерея, вопросы, форма предзаказа и смена темы работают без единой строчки JavaScript, на HTML, модификаторах Tailwind и токенах темы. Страница собирается через Vite и выкладывается на GitHub Pages.

Учебный проект Хекслета: https://ru.hexlet.io/programs/tailwind
Как это должно работать: https://files.hexlet.app/a/a7t5k9

## Стек
